# External Resources

Commnuity resources, mechanism examples, calculators and other tools. 
For vendors, see [Vendors](./vendors).

## Community

| Resource | Use it for |
|---|---|
| [Chief Delphi](https://www.chiefdelphi.com) | The main FRC forum. Someone may have already asked a similar question. FRC news is also posted here. |
| [Open Alliance / Build Blogs](https://www.chiefdelphi.com/c/first/build-blog/12149) | Teams sharing their whole season as it happens: prototypes, test results, full CAD |
| Discord | Unofficial FRC Discord, FRC Australia Discord, David's Design Server (Great for CAD feedback) |

## Learning

| Resource | Use it for |
|---|---|
| [FRCDesign.org](https://frcdesign.org) | The primary way we reccomend you learn how to use Onshape / CAD for FRC. Step by step tutorials suitable for all skill levels. They also include good CAD practices, mechanism examples, and other resources. |
| [Onshape Learning Center](https://learn.onshape.com) | Official courses, for more depth on a specific tool |

## Tools

| Resource | Use it for |
|---|---|
| [ReCalc](https://www.reca.lc) | Mechanism calculator: helps pick gear ratios, calculate c2c distances, etc. |
| [AMBCalc](https://ambcalc.com) |Another mechanism calculator |
| [Game Manual](https://www.firstinspires.org/resource-library/frc/competition-manual-qa-system) | Robot rules |

## Robot Examples

| Resource | Use it for |
|---|---|
| [Project B Encyclopaedia](https://www.projectb.net.au/resources/robot-mechanisms/) | Library of mechanisms made by team 5985. Good for inspiration on intakes for different types of game pieces. |
| [Robot Showcase](https://www.chiefdelphi.com/c/first/robot-showcase/37) | Robot reveals, CAD links and technical binders. Best searched with a particular year in mind. |
| Vendor designs | Each year REV, WCP, and other vendors will publish a robot design. Also look at the Everybot robot design. |
| Ri3D | After kickoff, search YouTube with "FRC Ri3D" for robots built for the new game in 3 days |
| [Behind the Bumpers](https://www.youtube.com/playlist?list=PLkZ6_Ld1x9Y_GDGwzzxD_vi_5tnlmAWJo) | Short robot walkthroughs filmed at competitions |
| [The Blue Alliance](https://www.thebluealliance.com) | Match videos and robot photos for any team or event |
