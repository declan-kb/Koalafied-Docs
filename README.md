# Koalafied Docs

Experimental docs / wiki page built with [VitePress](https://vitepress.dev) that Declan is messing around with. 

**Live site:** https://declan-kb.github.io/Koalafied-Docs/

It is designed to contain evergreen documentation, guides, reference material (i.e. things that aren't constantly being edited)

Pages are written in markdown (I like Markdown a lot...). You can export Word Documents to markdown pretty effectively, and essentially drop them directly into the wiki (after adding to the nav bar).

There is, importantly, a dark mode. 

## Editing
It is designed to be as easy to edit as possible. 

Click **Edit this page on GitHub** at the bottom of any page. That's most of it. 

See [How to edit](docs/contributing/how-to-edit.md) for the full guide, including how to add pages and images.

Pushing to `main` deploys automatically via GitHub Actions (`.github/workflows/deploy.yml`).
